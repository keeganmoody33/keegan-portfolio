# Fraunces (source for the Hathaway wordmark)

SIL Open Font License 1.1. Full text in `OFL.txt`.

- Upstream: https://github.com/undercasetype/Fraunces
- File: `Fraunces[SOFT,WONK,opsz,wght].ttf` from Google Fonts `ofl/fraunces`
- Instance used by `scripts/build-wordmark-hathaway.py`:
  - weight (`wght`) **900**
  - `SOFT` **100**
  - `WONK` **0**
  - optical size (`opsz`) **144**

The wordmark is outlined SVG path data, not a live web font. Customization is spacing, an `o` center dot, and rounding sharp serif ends — not new letter skeletons.

Reserved Font Name: Fraunces. This logo is a document created with the font, not a modified font named Fraunces.
